# 📚 BookNest — Book Explorer

BookNest is a book discovery website that helps readers explore books, search for their next favorite story, read book details, and save favorite books.

## 🌟 Features

- **Explore Books:** Browse a collection of books.
- **Search Books:** Search for books by title or other available information.
- **Book Details:** Open a separate page to view book information and story previews.
- **Favorites:** Save favorite books and access them from the Favorites page.
- **Responsive Design:** Designed to work on desktop and mobile screens.
- **Reader-Friendly Interface:** A clean interface built for book lovers.

## 🛠️ Technologies Used

- HTML5
- Tailwind CSS
- JavaScript (ES Modules)
- Vite
- Open Library API
- Local Storage
- Vercel

## ⚙️ Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/saronelly123-ui/book-explorer-project.git
   ```

2. Open the project folder:

   ```bash
   cd book-explorer-project
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL shown in your terminal.

## 🏗️ Build for Production

Run the following command:

```bash
npm run build
```

The production files will be generated in the `dist` folder.
